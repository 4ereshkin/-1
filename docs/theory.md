# Математика и ответы для защиты

## Модель и осознанные отличия от кода методички

Для каждой оси и постоянного ускорения на шаге Δt = 0.05 с:

```
p_next = p + v·Δt + a·Δt²/2
v_next = v + a·Δt
```

Для истины используется введённое ускорение, для оценки — `a + b`,
где b = 0.02 м/с² по каждой оси. При старте из покоя до первой коррекции:

```
p_true(t) = p0 + a·t²/2
p_est(t)  = p0 + (a+b)·t²/2
error(t)  = hypot(x_est-x_true, y_est-y_true)
          = sqrt(2)·0.02·t²/2
```

Например, за 10 с ошибка по каждой оси 1 м, суммарная — около 1.414 м.
Это систематическое смещение акселерометра, не случайный шум.

В примере PDF истинная скорость вообще не накапливается: добавляется только
`a·Δt²/2` на каждом шаге. Это не равноускоренное движение и создаёт огромную
искусственную ошибку даже без дрейфа. Здесь обе ветви используют одинаковое
точное интегрирование постоянного ускорения. На эскизе дрейф подписан в м/с,
но в коде складывается с ускорением; поэтому в нашем интерфейсе его единицы
исправлены на **м/с²**. Сравнивать 0.02 м/с² с 0.01 м/с из вопроса 3 напрямую нельзя.

Коррекция сохранена как в пункте 5: позиция оценки = истинной, оценённая
скорость = 0. Это не оценка истинной скорости движущегося БПЛА: после такой
коррекции возникает дополнительная ошибка скорости. В реальном фильтре
корректируются согласованные оценки состояния по доступным измерениям;
копирование идеальной истины здесь лишь учебная имитация внешнего датчика.

## 1. Почему ИНС накапливает ошибку?

Акселерометр имеет смещение нуля, шум и ошибки масштаба. Ошибка ориентации
также приводит к неправильному вычитанию гравитации. Ускорение интегрируется
в скорость, затем в координату. Постоянное смещение ускорения b даёт ошибку
скорости b·t и координаты b·t²/2. ИНС без внешнего источника информации не
может отличить такое смещение от настоящего ускорения.

## 2. Что такое комплементарный фильтр?

Он объединяет взаимодополняющие частотные свойства датчиков: быструю,
плавную, но дрейфующую оценку ИНС и более медленную абсолютную информацию
внешнего датчика. Простейшая дискретная иллюстрация для одной координаты:

```
x_fused = α·x_INS_predicted + (1−α)·x_external
```

Здесь прогноз ИНС строится из предыдущей объединённой оценки; α близкое к 1
даёт больше веса прогнозу. Для простой схемы α можно связать с постоянной
времени τ: `α = τ/(τ + Δt)`. Измерения должны относиться к одному времени,
системе координат и физической величине. Обычно ИНС обеспечивает
высокочастотную составляющую, внешний датчик — низкочастотную. Комплементарный
фильтр не следует путать с мгновенным сбросом, реализованным кнопкой задания.

### Фильтр в программе

Оранжевая траектория хранит собственные координаты и скорость. На каждом шаге
0.05 с они прогнозируются по ускорению со смещением `b = 0.02 м/с²`.
Прогноз начинается с предыдущего скорректированного состояния. На окружности
используются те же точные интегралы ускорения, что и для остальных траекторий.

Внешний датчик имитируется измерением `z = p_true + noise` раз в `h = 0.2 с`.
Шум нормальный, независимый по осям, со стандартным отклонением из поля
«Шум датчика». Истинная позиция доступна генератору измерений и подсчёту ошибок;
в формулы поправок поступает только измерение `z`.

Используется дискретный комплементарный фильтр второго порядка: поправки
получают и координата, и скорость. Для каждой оси при новом измерении:

```
residual = z - p_predicted
q = exp(-h / tau)
position_gain = 1 - q²
velocity_gain = (1 - q)² / h
p_filtered = p_predicted + position_gain * residual
v_filtered = v_predicted + velocity_gain * residual
```

`residual` — расхождение измерения и прогноза, в метрах. `tau` задаётся полем
«Время реакции». Коэффициент позиции безразмерный, коэффициент скорости имеет
единицы 1/с. Скорость оценивается через обратную связь по координатам;
измерение скорости от внешнего датчика не требуется.

Для ошибки состояния между последовательными измерениями оба собственных
значения матрицы перехода равны `q`: это коэффициенты затухания отклонений.
При положительном `tau` они находятся между 0 и 1. При отсутствии смещения и
шума начальная ошибка затухает. Меньшее `tau` даёт более сильные поправки,
но передаёт больше шума. Смещение акселерометра отдельно не оценивается,
поэтому даже идеальный внешний датчик не гарантирует нулевую ошибку между
поправками. Это учебная модель без ориентации, гравитации и задержки измерений.

При выключенной автокоррекции или недоступном датчике выполняется только
прогноз по ИНС. Переключение не изменяет текущее состояние. После включения
поправки возобновляются с ближайшим новым измерением; старые измерения повторно
не используются. На паузе модельное время и датчик остановлены.
Кнопка разовой коррекции из задания действует только на синюю оценку ИНС.

## 3. Как часто нужна коррекция при дрейфе 0.01 м/с?

Одного значения дрейфа недостаточно: нужен допустимый предел ошибки позиции.
Если 0.01 м/с — постоянная скорость роста ошибки, то
`T_max = E_max / 0.01`. Например, для допуска 1 м это 100 с,
для 0.1 м — 10 с. Это математические примеры, не норматив полётной эксплуатации.
Если 0.01 м/с относится к каждой из двух осей, модуль скорости ошибки равен
`sqrt(2)·0.01`, и интервал для общего допуска 1 м около 70.7 с.

Если же имеется в виду смещение акселерометра b в м/с², ошибка квадратичная:
`T_max = sqrt(2·E_max / |b|)` для одной оси с нулевой начальной ошибкой скорости.
В настоящей системе период зависит от датчиков, динамики, доступности внешних
измерений и требуемой точности; универсального интервала для всех малых БПЛА нет.

## Дополнительный режим: окружность

Пусть R — радиус, T — период, ω = 2π/T, центр C = (300−R, 200).
Идеальное движение задаётся `p(t) = C + R·(cos(ωt), sin(ωt))`.
Его скорость `v(t) = Rω·(−sin(ωt), cos(ωt))`,
ускорение `a(t) = −Rω²·(cos(ωt), sin(ωt))` постоянно по модулю, но не по направлению.
Начальная ненулевая скорость нужна для движения по окружности, а не падения к центру.

На каждом шаге модель использует точные интегралы этих компонент ускорения.
Истина и оценка интегрируются из **собственных** координат и скоростей, при этом
в оценку дополнительно вносится постоянное смещение акселерометра. Это не
рисование двух готовых окружностей: после коррекции скорость оценки сброшена,
поэтому дальнейшая оценка интегрируется с другим начальным условием.
До первой коррекции ошибка по каждой оси равна `0.5·b·t²`, как и в базовом режиме.

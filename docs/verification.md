# Проверка реализации (2026-10-07)

## Текущая версия: фильтр, SVG и MP3 на Windows

Повтор аудио дополнительно проверен в `build-audio-loop`: по сигналу конца записи
проигрыватель явно перематывается и запускается заново, если движение и звук включены.
Новый тест дождался двух естественных окончаний MP3 без перемотки и подтвердил
воспроизведение следующего цикла после каждого. CTest: 2/2 passed, 48.04 с.
Отдельная проверка управления звуком на платформе Windows также прошла.
Сборка размещена отдельно, чтобы не закрывать уже запущенный пользователем симулятор.

Проверена Release-сборка с Qt 6.12.0, MinGW 13.1 и Ninja. CTest: 2/2 passed.
QtTest на платформе Windows: 10 passed, 0 failed, включая начальную и завершающую
проверки. Старое предупреждение об устаревшем конструкторе QMouseEvent в тесте
камеры сохраняется. Qt 5 и MSVC для этой версии не проверялись.

- Модель: включение и отключение автокоррекции на ходу сохраняет состояние;
  после включения ошибка уменьшается в обоих режимах движения.
- Датчик: измерения приходят раз в 0.2 с, старые показания повторно не применяются;
  проверены потеря и восстановление измерений, шум и повторяемость после сброса.
- Фильтр: поправляются координаты и скорость; проверены границы параметров,
  независимость истины и исходной ИНС, отсутствие влияния разовой коррекции на фильтр.
- Интерфейс: все настройки фильтра доступны на ходу, пауза и сброс сохраняют
  выбранные параметры; на сцене три траектории.
- SVG: ресурс загружается, центр иконки совпадает с истинной позицией при повороте;
  размер сохраняется при зуме, пауза и сброс работают.
- MP3: проверены загрузка и декодирование, запуск, пауза, возобновление,
  выключение во время движения, переход конца записи к началу и сброс позиции.
  Автотест воспроизводит запись с отключённым звуковым выходом, не проверяет
  субъективное качество звучания динамиков.

Просмотрены `build-windows/circle-preview.png` и `build-windows/filter-preview.png`:
видны дрон, три траектории, настройки фильтра и переключатель звука.
На снимке окружности при 40 с ошибка ИНС 22.627 м, фильтра 0.450 м
(радиус 100 м, период 40 с, шум 0.5 м, время реакции 2 с).

Библиотеки Qt, мультимедийный модуль и зависимости FFmpeg размещены рядом с EXE
через windeployqt. Нативные тесты затем прошли без добавления путей Qt в PATH.
SVG и MP3 встроены в ресурсы приложения; исходные файлы пользователя не изменены.

## История проверки исходной версии на Linux

| Требование | Реализация и проверка |
|---|---|
| C++ / Qt Widgets | CMake, GCC 13.3, Qt 5.15.13; Debug и Release собраны |
| Форма .ui, имена из таблицы | src/mainwindow.ui; AUTOUIC; открытие установленным Designer без ошибок |
| Одно окно и одна сцена | MainWindow, QGraphicsScene; GUI-тест проверяет элементы сцены |
| Ускорения X/Y | lineEditAx / lineEditAy; проверены оба поля, нечисловые и предельные значения |
| QTimer 20–100 мс | 50 мс; тест проверяет интервал и реальное поступление тиков |
| Истина и оценка, дрейф | Две траектории и маркеры; аналитические тесты и просмотр снимка |
| Старт, коррекция, сброс | GUI-тесты и отдельные проверки модели; коррекция даёт нулевую ошибку |
| Статус, ошибка | labelStatus; проверки времени/ошибки до и после действий |
| Контрольные вопросы | docs/theory.md, три ответа с формулами и оговорками |
| Запуск | Графический запуск Release без ошибок; завершён timeout через 3 секунды |

Debug: CTest 2/2 passed. Release: CTest 2/2 passed. Оба тестовых исполняемых
файла содержат множество отдельных проверок; проверки модели не отключаются
в Release. Cppcheck warning/performance/portability: без диагностик после
настройки Qt-макросов. Предупреждения компилятора Wall/Wextra/Wpedantic: нет.

Снимок тестового окна: build/window-preview.png. Визуально проверены обе линии,
маркеры, подписи, значения и размещение элементов по эскизу.

Ограничения доказательств: Windows MinGW/MSVC и Qt 6 не запускались, Qt Creator
не установлен; графический smoke-тест не заменяет интерактивную приёмку
пользователем. Полноценный навигационный фильтр не входит в вариант: модель
учебная, с постоянным смещением акселерометра. Отличия от ошибочного
интегрирования PDF явно описаны в docs/theory.md.

## Сетка, ручная камера и окружность

После расширения повторно собраны Debug и Release, CTest 2/2 passed в каждой.
GUI-проверки теперь включают колесо около указателя, перетаскивание мышью,
стрелки, +/- и F, синхронизацию галочки автообзора, сохранение масштаба при
resize, отсутствие сдвига ручной камеры за 2400 шагов модели, круговой режим,
паузу/продолжение и паузу до первого тика. Модель проверена на пяти оборотах,
аналитических радиусе/скорости/ускорении, квадратичном дрейфе и коррекции.
Cppcheck warning/performance/portability прошёл без диагностик.
Снимки window-preview.png и circle-preview.png просмотрены: видны сетка,
подписи координат, легенда, подписи точек и обе траектории.
